Retro Calculator: Basic and Scientific Modes in One Offline App

24 October 2026 · updated 29 October 2026 · by the developer of Orbitika

Short answer: The Calculator in Orbitika is a free tool with two modes. Basic does the four operations, percent, sign change and backspace. Scientific adds sin, cos, tan with a RAD/DEG switch, log, ln, squares, cubes, roots, 1/x and pi. It is designed to work without Wi-Fi or mobile data.

Here’s a small test of how much we trust our phones: how many times have you opened a browser just to add up some numbers, then waited for a page full of ads to load? I wanted the opposite. A calculator that opens instantly, looks like the pocket calculators I grew up with, and doesn’t need a signal.

So Orbitika’s Calculator has two modes, Basic and Scientific, on purpose. Most days you only need the first. When you need the second, it’s one tap away.

What it does

You open the tool and see a large display and a keypad. At the top are two buttons, BASIC and SCI. The title bar changes with the mode: it says CALCULATOR in Basic and SCIENTIFIC in Scientific. Switching modes clears the calculation, so you always start from a clean screen. Every key press gives a light vibration, and keys dim briefly while you press them, so the buttons feel like real ones.

Basic mode

The Basic keypad has digits 0 to 9 and a decimal point, the four operations (÷, ×, −, +), an equals key, and three helpers:

  • C clears everything.
  • ± flips a number between positive and negative.
  • % divides the number on screen by 100, so 50 becomes 0.5.

A small line above the main display shows the calculation as you go, so you can see what you’ve done before you trust the answer.

Scientific mode

Scientific mode keeps the same digits and operations and adds a block of function keys on top, plus a ⌫ backspace key that removes the last digit you typed:

  • sin, cos, tan for trigonometry, with a RAD/DEG key that switches between radians and degrees. The key shows the mode you are in, and the calculator starts in radians.
  • log (base 10) and ln (natural log).
  • x², x³, √ and ∛ for squares, cubes, square roots and cube roots.
  • 1/x for reciprocals.
  • π to insert the value of pi.

The function keys work on the number currently on the display. Type 16, press √, and you get 4, with the line above showing “√(16)”. To check an angle, make sure the RAD/DEG key shows the mode you want first, then type the angle and press sin, cos or tan.

How results are shown

Whole numbers up to just under a trillion appear in full, without a trailing “.0”. Very long decimals switch to exponent notation so they fit on the screen. If something can’t be calculated, such as dividing by zero, the display says Error instead of a nonsense number.

Why it’s offline

The Calculator is designed to work without Wi-Fi or mobile data. All the maths is done on the phone, so it works on a plane, in an exam room or in a basement car park. It also needs very little from the phone, which is helpful on an older device.

Who it helps

Students who need sin, cos and logs for homework, shoppers working out totals, anyone splitting a bill, tradespeople doing quick sums, and travellers who don’t want to rely on a web calculator abroad.

A few tips

  • Check RAD or DEG before any trig. It’s the most common cause of “wrong” answers, because sin(90) is very different in each mode.
  • Read the line above the display. It shows what the calculator thinks you asked.
  • Use ± instead of retyping. It flips the sign of the number on screen.
  • Use % as a quick divide by 100. It’s handy for turning a percentage into a decimal.

An honest limit

This calculator works the way a classic pocket calculator does: one step at a time, left to right. That means it doesn’t apply the usual order of operations. If you type 2 + 3 × 4, it works out 2 + 3 first and then multiplies by 4, giving 20, where a calculator that follows order of operations would give 14. For longer calculations, work through the parts in the order you want them done. It also isn’t a graphing or programmable calculator.
